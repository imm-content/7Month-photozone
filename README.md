# 왕·왕비 AR 포토존

창덕궁 인정전 추억 인증샷을 위한 웹 기반 AR 포토존입니다.

- 실행: https://imm-content.github.io/7Month-photozone/
- 저장소: https://github.com/imm-content/7Month-photozone

## 촬영 모드

| 모드 | 카메라 | 이미지 |
|---|---|---|
| 셀프촬영 1인 상반신 | 전면 | royal_self.png |
| 타인촬영 1인 상반신 | 후면 | royal_people.png |
| 타인촬영 1인 전신 | 후면 | royal_single.png |
| 타인촬영 2인 전신 | 후면 | royal_couple.png |

모드를 선택하고 왕·왕비 이미지 크기를 조절한 뒤 촬영합니다. 결과 이미지를 길게 눌러 저장하거나 공유할 수 있습니다.

## 2026-11-26 개선

- 메뉴 및 브라우저 제목 변경. 기존 부제, 이미지, 촬영 기능 유지.
- 기존 후면 카메라 요청 실패 시 장치 목록을 조회하여 개별 카메라를 자동 탐색합니다. 일반 조건 및 저해상도 조건을 시도하며 특정 기종이나 장치 ID를 고정하지 않습니다.
- 장치 방향을 확인하여 후면 촬영에 전면 카메라를 사용하지 않습니다. 장치 목록 확보를 위해 기본 카메라를 잠시 열 수 있습니다.
- 카메라 시작 절차의 대기 제한은 60초이며 실패 시 메뉴로 돌아갑니다. 늦게 반환되는 스트림도 해제합니다. 운영체제의 요청 자체를 취소하는 것은 아닙니다.
- 권한 오류와 일반 실행 오류를 구분하고 재접속 및 재부팅을 안내합니다.
- 모드 변경 및 페이지 이탈 시 카메라 스트림을 해제합니다.

## 배포 및 검증

기존 저장소의 index.html과 README.md만 교체합니다. 네 PNG 파일은 유지합니다. HTTPS 환경에서 카메라 권한을 허용해야 합니다.

Galaxy A36 5G, Wide5, Z Flip5에서 전면 및 후면 모드 3종, 모드 전환, 크기 조절, 촬영 및 저장을 확인하고 3회 반복 접속합니다. 실제 기기 검증은 배포 후 진행합니다.
